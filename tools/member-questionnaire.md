# SJTUfur 官网成员资料收集表

在腾讯文档中新建空白在线收集表。以下题目名称请保持一致，导入工具按题目名称识别列，顺序可以调整；腾讯自动添加的提交时间、填写人、序号等列会忽略。

## 标题与说明

标题：**SJTUfur 官网成员资料收集**

说明，可直接复制：

> 邀请你在荣毛社官网的成员页介绍自己！填写昵称、兴趣和一句话简介，让大家认识你。头像和个人网页均为选填。
>
> 只有你明确同意公开展示后，我们才会把这份资料加入成员页。QQ 是否展示由你单独选择；不公开的 QQ 仅供管理员联系，不会导入官网资料。填写本表不等同于完成入社，校内同学入社仍请联系管理员。

## 题目设计

| 题目名称 | 题型 | 必填 | 设置与提示语 |
| --- | --- | --- | --- |
| 昵称 | 单行填空 | 是 | 希望在官网展示的名字，不必填写真实姓名。请保持昵称稳定，方便后续核对。 |
| 兴趣方向 | 单行填空 | 否 | 例如：绘画、摄影、兽装、音乐、桌游。可写多个，用顿号分隔，建议 20 字以内。 |
| 一句话简介 | 多行填空 | 否 | 向大家介绍自己，建议 60 字以内。留空则不显示简介。 |
| 个人网页 | 单行填空 | 否 | 个人主页、B 站、作品集等任选一个。填写完整网址，以 https:// 或 http:// 开头。 |
| 启用名字链接 | 单选 | 是 | 选项只写“是”“否”。选“是”后，成员页的名字将可点击并跳转到上面的个人网页；无网页请选择“否”。建议不预选。 |
| QQ | 单行填空 | 否 | 仅填 QQ 号码数字，不填 QQ 群号。用于管理员核对和联系；是否展示由下一题选择。不要使用数字金额题型。 |
| 公开QQ | 单选 | 是 | 选项只写“是”“否”。选择“是”代表同意在公开官网显示本题填写的 QQ；建议不预选。 |
| 头像 | 图片上传 / 附件上传 | 否 | 最多 1 张 PNG/JPG，建议正方形，不超过 2 MB。请使用有权公开的头像或角色图片。建议文件名包含昵称，方便管理员对应。 |
| 同意公开展示 | 单选 | 是 | 选项只写“是”“否”。说明：“我同意将昵称、兴趣方向、简介、头像及选择开启的个人网页展示在社团公开网站上；QQ 是否公开按上一题的选择处理。”不要预选。 |

“分组 / 管理员”由维护者在编辑工具里设置，不作为问卷题目。Excel 导入的新成员统一进入“社员”分组。

如果当前收集表版本支持题目逻辑，可以在选择“启用名字链接：是”时提示填写个人网页。即使未配置逻辑，导入工具也会把缺少有效网址的记录列为待修正。

## 收集表设置建议

- 允许填写人提交后修改，尽量每人只保留一份回复。
- 将完整结果限定为维护人员可见；成员只需获得填写链接。
- 不收集本流程不使用的学号、真实姓名、院系等额外身份信息。
- 发布前先用一份测试回复确认题目列名和导出结果。

腾讯文档官方说明支持关联收集表结果到在线表格，也支持设置提交后修改及重复提交等选项。不同客户端的入口名称可能不同：见[腾讯文档官方操作指南](https://cloud.tencent.com/document/product/1663/103166)。

## 从 Excel 导入成员编辑工具

1. 收集结束后，在收集结果中关联 / 查看结果表格，从表格菜单导出为本地 `.xlsx`。不要导出为 PDF、截图或统计图。无需删除提交时间、填写人等额外列，也无需手工调整题目顺序。
2. 用浏览器打开工程中的 `tools/members-editor.html`，点击“导入 Excel”，选择下载的 `.xlsx`。
3. 预览会显示可新增成员、跳过记录和需修正记录。存在多个符合列名的工作表时，在弹窗中选择正确的回复表。点击“确认追加”后才会改变编辑器中的成员列表。
4. 仅导入“同意公开展示”为“是”的记录。QQ 只有“公开QQ”为“是”才进入官网资料。名字链接仅在明确开启且网页有效时启用。
5. 现有成员保持原样。同名记录（包括同一份 Excel 内重复的昵称）会跳过并列出原因；本工具不会凭昵称覆盖已有资料。需要更新同名成员时，请核对本人后在编辑器手动修改。
6. 对“需修正”记录，按提示在原表格中补齐或修正，再次导入。第一次已追加的昵称会被跳过。
7. 完成检查后，通过本地编辑服务点击“应用到工程”保存；也可下载成员资料并替换工程根目录的 `members-data.js`，再按原来的 PR 流程提交发布。导入、应用和下载都不会自动发布网站。

导入仅在本机浏览器运行，不上传 Excel，也不把仅用于管理员联系的 QQ 保存到官网资料。支持不超过 10 MB、5000 条回复的 `.xlsx`；旧版 `.js` 资料备份仍用原来的“导入资料”按钮。

## 头像的单独处理

Excel 中的头像列可能是附件名称、下载链接或图片，而工程当前使用本地图片路径。**Excel 导入不会自动下载头像附件或提取嵌入图片。**

1. 另外从腾讯文档下载头像附件，按昵称核对后放入 `assets/images/people/`。
2. 在成员编辑器里点击该成员的“更多”，填写例如 `assets/images/people/某昵称.png`，查看头像预览。
3. 将图片和导出的 `members-data.js` 一起提交。没有头像时，成员页使用默认头像。

如果由维护者额外整理了一列“头像路径”，导入工具也会识别，但路径须指向已有的 `assets/images/` 下的图片。问卷里不应让成员自己填写工程路径。
